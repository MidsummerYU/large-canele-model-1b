# SimpleQA grader prompt

`simpleqa_grader.txt` is the `GRADER_TEMPLATE` of OpenAI's simple-evals, copied unchanged from
https://github.com/openai/simple-evals/blob/main/simpleqa_eval.py (MIT License, Copyright (c) 2024 OpenAI).
It grades a predicted answer against a gold target as A (correct), B (incorrect) or C (not attempted).
